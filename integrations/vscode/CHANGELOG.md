# Changelog

## 0.1.0

First release.

- A chat view in the activity bar. Replies stream in and each tool the agent runs is listed.
- Permission questions can be answered in the chat or in a notification.
- Commands: ask the agent, ask about the selection, fix the problems in this file, stop, new conversation, open the dashboard, show the agent log.
- Finds the ABP desktop app or a checkout by itself. No token to copy.
- `abp.model` defaults to `auto`: ABP's router picks the model, and never Claude unless you choose it.
